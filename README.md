<h1 align="center">Centro Médico Reviver</h1>

<p align="center">
Sistema de gerenciamento hospitalar desenvolvido em <strong>PHP puro</strong>, utilizando a arquitetura MVC. Projeto foi desenvolvido para fins educacionais, servindo como material de estudo para estudantes do Ensino Médio Técnico e Ensino Superior. Bem como para Trabalhos de Conclusão de Curso (TCC).
</p>

# Como executar o projeto

Clone o projeto

```bash
git clone https://github.com/DeniseMendess/CentroReviver
```

Entre na pasta

```bash
cd CentroReviver
```

Instale as dependências

```bash
composer install
```

## Banco de dados

Crie o banco de dados no MySQL e importe o arquivo SQL:
<br>
[! Importar Banco de dados](./database/centroreviver.sql).


Inicie o Apache e o MySQL.

Abra no navegador

```
http://localhost/CentroReviver
```
